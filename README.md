# ConfigFiles Repository

Este repositorio contiene una colección de archivos de configuración (`configFiles`) para diversas aplicaciones y herramientas que utilizo.

## Contenido

- **Code - OSS**
- **World of Warcraft Addons**
  - Details
  - WeakAuras
  - ElvUI

## Cómo Contribuir

1. Haz un fork del repositorio.
2. Agrega o modifica los archivos de configuración.
3. Haz un commit con tus cambios.
4. Haz un push a tu rama.
5. Abre un Pull Request para revisión.
